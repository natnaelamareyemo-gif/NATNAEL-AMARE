HTML Tag Reference Cheat Sheet

Quick copy references for structures, forms, lists, and semantic HTML layouts:

Document Base

<!DOCTYPE html> Informs browser of HTML5 version. <html> The master folder wrapper. <head> Houses web title, metatags config, and styles. <body> Holds main visible webpage content.

Text Formatting

<h1> to <h6> Heading levels 1 (largest) down to 6. <p> Creates standard text spacing paragraphs. <br> Forces a single line break in body text. <strong> Displays text characters in heavy bold. <em> Formats letters in italics. <mark> Highlights target selection in yellow neon.

Tables & Columns

<table> Declares grid table outline. <tr> Specifies an individual table row. <td> Houses a standard row data cell. <th> Table grid headings (centered + bold). colspan="X" Merge cell horizontally across columns.

Interactive Forms

<form> Container wrapping inputs and dispatcher. <input type="X"> Inputs like text, password, and email. <textarea> Larger text boxes for review comments. <select> Initializes dropdown popup drawer lists.
